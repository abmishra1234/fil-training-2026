# Laptops and IT Assets (IT-POL-02)

## Standard laptop
Engineers receive a 16 GB or 32 GB laptop, refreshed every 4 years. Additional monitors can be requested through the IT service portal "HelpNova".

## Lost or stolen device
If a laptop, phone or access card is lost or stolen, report it to the IT service desk within 2 hours so that the device can be remotely wiped and accounts can be secured. A police complaint (FIR) copy is required within 7 days for stolen devices. The first replacement is free; a second loss within 2 years is charged at the depreciated value.

## Software installation
Only software from the self-service "AppStore" catalogue may be installed. Other software needs an exception request approved by Information Security.

## USB storage
USB mass-storage devices are blocked on all company laptops. Use the approved file-sharing tool for transferring files.

## Returning assets
All assets must be returned on the last working day. The full and final settlement is processed only after IT confirms the return.
